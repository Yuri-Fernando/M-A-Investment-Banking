# Referências metodológicas e fontes de dados

Referências para o desenho e a interpretação do sistema. Links não são snapshots nem cotações contemporâneas. Nenhum dado público é apresentado como demonstração privada da empresa fictícia.

| Fonte | Aplicação | Limite |
|---|---|---|
| [CFA Institute: Free Cash Flow Valuation](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation) | FCFF/FCFE, desconto e terminal | Premissas do caso continuam ilustrativas |
| [CVM DFP](https://dados.cvm.gov.br/dataset/cia_aberta-doc-dfp) | Demonstrações anuais de emissores | Conferir escopo, conta, versão e publicação |
| [CVM ITR](https://dados.cvm.gov.br/dataset/cia_aberta-doc-itr) | Demonstrações intermediárias | Identificar fluxo cumulativo e reapresentações |
| [BCB: serviços de dados](https://www.bcb.gov.br/gestao_site/webservices.asp?frame=1) | Referência para pesquisa macro futura | Não é uma calibração automática de WACC |
| [Damodaran: dados](https://pages.stern.nyu.edu/adamodar/New_Home_Page/datacurrent.html) | Pesquisa de risco e estrutura de capital | Registrar moeda, versão, data e risco já incorporado |
| [B3: cotações históricas](https://www.b3.com.br/pt_br/market-data-e-indices/servicos-de-dados/market-data/historico/mercado-a-vista/cotacoes-historicas/) | Possível etapa de cotações de peers | Preços/ações/classes/eventos e direitos precisam de revisão |

## Política

Cada snapshot externo deve registrar URL, publisher, data de captura, disponibilidade histórica, licença, hash e decisões de mapeamento. Não se mistura valor público de companhia real com o identificador sintético.

Nesta distribuição não há cotação real, transação comparável, TAM ou market share verificado pré-carregado. A taxa tributária de 34% é hipótese simplificada, não um parecer tributário. Não se publica conclusão jurídica automática sobre CADE, LGPD ou validade de contratos.
